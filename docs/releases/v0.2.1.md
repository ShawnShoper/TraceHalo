# TraceHalo v0.2.1 Beta 升级说明

`0.2.1 Beta`（build 39），2026-11-09。本次更新集中改善应用卸载的排版、数据选择和权限准备，并修复主窗口无法打开的问题。

这是待合并的本机验证候选版。公开安装包、Apple 公证和 GitHub Release 尚未发布；下载版本以 [Releases 页面](https://github.com/ShawnShoper/TraceHalo/releases)为准。

## 应用列表更直接

- 每行显示一个应用，图标、名称、版本、磁盘占用和「卸载」按钮分别对齐。搜索与刷新集中在列表顶部，卸载选项在独立窗口中打开。
- 每行都有明确的「卸载」按钮，按钮名称不再带省略号。重名应用可通过路径区分。

## 本机数据由你选择

- 卸载默认保留本机数据。选择清理后，初始不勾选任何文件；只有选中的候选文件才会一起移到废纸篓。
- 「全选／取消全选」覆盖范围内的全部候选数据，包括归属未确认的目录、共享数据和保存的内容。这些项目可以单独勾选，并明确显示归属线索及清理影响。
- 最终确认页可滚动查看全部待移除路径，并汇总「归属未确认」「共享数据」「保存的内容」提示。未选中的候选文件列在保留清单中；点击「确认移除」前不会执行移除。
- 同时选中父文件夹和子项时，只移动外层文件夹一次。取消勾选子项会同时取消其已选父目录，避免未选项目被间接清理。

## 数据查找更完整、说明更清楚

- 在原有应用标识匹配基础上，参考同厂商签名组件、应用群组、启动记录、安装收据和脚本中的固定路径，补充可能相关的文件。
- 列表显示文件用途、可能的清理影响、路径和能够统计到的磁盘占用。仅凭名称或路径引用发现的项目会标为「归属未确认」，不会冒充已确认的归属。
- 只读取有限范围的元数据和脚本文本，不执行第三方脚本，不读取个人文稿内容，也不保证找出全部历史数据。
- 系统范围路径、符号链接等不能在此处理的项目仍会说明原因。厂商驱动、系统扩展和系统组件应使用厂商卸载器处理。[数据查找与清理边界](../application-data-discovery.md)

## 首次准备卸载权限

- 首次打开主窗口时，按需提供一次可跳过的「卸载功能准备」引导。之后可在「设置 → 卸载权限」继续配置，不必每次卸载都重新选择系统设置入口。
- 卸载助手与文件访问权限分别显示状态。需要完全磁盘访问权限时，会说明 TraceHalo 和 TraceHaloUninstallHelper 两个条目，以及如何在 Finder 中找到对应程序。
- 返回应用后重新检查实际访问状态。打开过系统设置或点过配置按钮，不会被当作已获得权限。
- 配置不完整时，卸载页面显示提示和设置入口。系统要求的管理员验证及最终移除确认仍保留；普通监控可以在不配置这些权限的情况下使用。

## 主窗口启动与恢复修复

- 修复进程仍在运行、主窗口却无法正常打开的情况，明确主窗口启动行为。
- 保留窗口创建完成前收到的打开请求，改善冷启动、关闭窗口后重新打开，以及从菜单栏模式返回主界面的恢复流程。

## 升级与验证

- 支持 macOS 14 及以上，构建包含 Apple Silicon 和 Intel 两种架构。升级前请先选择「彻底退出 TraceHalo」，将新版放入「应用程序」后再打开。原有偏好设置继续保留。[安装与校验说明](../../DISTRIBUTION.md)
- 451 项自动化测试通过：421 项 XCTest、30 项 Swift Testing，零失败、零跳过。覆盖默认保留、全选与单选、共享及不确定归属标记、父子目录去重、未选文件保护和卸载执行检查。
- build 38 的功能已在本机用 Charles 完成全选、取消全选、单选、保留清单和最终确认流程复查；8 张原生快照覆盖中英文选择和确认页面。build 39 仅更新发布版本与元数据，功能代码与已验收的 build 38 一致，并完成回归、Universal 2 签名构建及本机安装验证。
- 验证未移除真实应用或个人数据，也未代替用户开启权限。真实共享数据移除、Intel Mac 实机、macOS 14 实机及全新机器权限批准流程仍需独立验收。公开发版还需完成 App 与 DMG 的 Apple 公证、票据、Gatekeeper 和校验值验证。
