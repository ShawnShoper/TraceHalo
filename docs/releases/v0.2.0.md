# TraceHalo v0.2.0 Beta 升级说明

`0.2.0`（build 26）已完成本机安装验证，源码待合并。Apple 公证与公开安装包发布待完成。

## 首页与报告

- 「实时监控」合并了概览和实时读数。CPU、内存、GPU、存储、网络和散热集中在首页，点卡片可原地展开核心、进程、磁盘、网络接口或传感器等详情。检测到内置电池时，额外显示电池与电源卡片。
- 首页可查看最近 15、30 或 60 分钟的资源趋势。网络统计按活跃物理网卡汇总，缺失的采样会留空。内存占用的小幅波动减少了重复事件。
- 「菜单栏布局」从实时监控顶部独立打开。修复了关闭主窗口后从菜单栏重新打开主程序失败的问题。
- 新安装默认使用浅色外观，已有用户的外观设置继续生效。修复了切换外观后主窗口仍显示旧配色的问题。
- 系统报告预览按面板宽度左对齐、自动换行。重新生成后回到页首，正文可以选择和复制，也可以分享或导出 PDF。

## 应用管理

- 应用列表显示实际图标、版本和后台统计的磁盘占用。缺失的版本或大小会明确标注。搜索结果改变时，只能操作当前可见的应用。
- 点击「卸载」会先显示确认页。默认保留本机数据，选择「同时清理本机数据」时只处理明确勾选的候选文件。应用和选中的文件会移到废纸篓。
- 清理列表支持「全选／取消全选」。点击「移到废纸篓」后仍会弹出最终确认，确认前不会执行移除。
- 应用本体先移动，确认成功后才处理选中的数据。应用移动失败或结果无法确认时会保留关联数据。清理中途失败时会显示完成数量和失败原因。
- 识别到厂商卸载器时会提示推荐入口，并可查看位置。支持直接打开识别到的图形卸载器。Docker Desktop 会打开自身，由用户进入「疑难解答 → 卸载」。只检测到命令行卸载程序时，应用会提供位置和 Finder 入口。

## 升级和权限

- 支持 macOS 14 及以上。替换旧版前先选「彻底退出 TraceHalo」，将新版放入「应用程序」后再启动。从旧版打开首页时，可通过「实时监控」进入新布局。[下载和校验说明](../../DISTRIBUTION.md)
- 符合条件的部分第三方应用需要先批准卸载助手并完成管理员认证，随后仍需确认要移除的应用和数据。若 macOS 拒绝访问废纸篓，TraceHalo 会提示所需权限，也可在 Finder 按系统提示处理。应用管理覆盖应用包和当前用户资料库中符合规则的候选文件。厂商驱动、系统扩展和其他系统范围组件应交给厂商卸载器。
- 本机验收以实际安装的构建为准，源代码测试和本机签名验证是独立环节。特权卸载验证要求 App 和助手均满足预设团队的 Developer ID 签名要求。公开包还需完成 App 与 DMG 的两阶段 Apple 公证、票据和 Gatekeeper 验证。[构建和验收说明](../../DEVELOPMENT.md)

## 验证记录（2026-11-06）

- 安全模式自动化测试：369 项 XCTest 与 30 项 Swift Testing，共 399 项通过、0 失败。
- Universal 2 Release 构建成功；本机安装后已确认版本为 `0.2.0 Beta (26)`，Developer ID 本地签名的深度、严格验证通过。
- 已生成 39 张界面回归快照；重点复查实时监控、菜单栏布局和中英文报告长行在标准、紧凑窗口下的显示。
- 报告行首、自动换行、重新生成回到顶部和页面切换已在前一功能构建 build 25 实测；build 26 仅更新版本元数据，功能代码一致。
- 本轮测试没有卸载真实应用或移动个人文件。Intel Mac 实机、全新机器的助手批准流程，以及新版 Apple 公证和公开安装包仍需独立验收。
